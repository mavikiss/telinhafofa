# ♡ Mavikiss Loading

Uma tela de carregamento animada feita do zero com **HTML, CSS e JavaScript**.

A ideia foi criar uma interface simples, delicada e com uma estética rosa, mas que ainda tivesse aquele toque de tecnologia. Em vez de usar uma animação pronta, toda a lógica do loading foi programada.

---

## ✦ Sobre o projeto

Este projeto é uma pequena página de loading criada para fazer parte do meu perfil do GitHub.

Durante a animação, a porcentagem aumenta gradualmente, a barra de progresso se movimenta e diferentes mensagens aparecem enquanto o sistema "carrega".

A intenção foi criar algo visualmente bonito sem deixar de ser um projeto de programação de verdade.

---

## ✿ O que o projeto faz

- Anima uma barra de progresso de **0% até 100%**
- Atualiza a porcentagem automaticamente
- Troca as mensagens durante o carregamento
- Possui efeito de brilho na barra
- Possui cursor piscando
- Reinicia a animação automaticamente
- Funciona diretamente no navegador
- Pode ser hospedado usando **GitHub Pages**

---

## ⌗ Tecnologias usadas

### HTML

Responsável pela estrutura da página.

Foi usado para criar elementos como:

- título
- mensagem de carregamento
- barra de progresso
- porcentagem
- terminal de status

### CSS

Responsável por toda a aparência.

Inclui:

- cores
- espaçamento
- bordas arredondadas
- barra de progresso
- gradiente rosa
- efeito de brilho
- animação do cursor

### JavaScript

Responsável pela parte interativa.

O JavaScript controla:

- porcentagem do carregamento
- velocidade da animação
- largura da barra
- troca das mensagens
- reinício do loading
- atualização dos elementos na tela
